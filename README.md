# kptVPN

Современный VPN-клиент для Windows на базе Xray и sing-box.

> Этот репозиторий используется для публикации установщиков и автоматических обновлений kptVPN. Исходный код закрытый.

## Возможности

- два режима подключения: локальный прокси и системный туннель «Весь трафик»;
- импорт отдельных конфигураций и подписок, включая Remnawave;
- поддержка VLESS, VMess, Trojan, Shadowsocks и Hysteria 2;
- транспорты TCP/RAW, WebSocket, gRPC, HTTP Upgrade и XHTTP;
- TLS и REALITY;
- автоматический выбор сервера по качеству соединения;
- задержка серверов, статистика скорости и использованного трафика;
- автоматическое обновление подписок, Xray, sing-box и самого приложения;
- автозапуск, работа в системном трее и подключение при запуске Windows.

## Системные требования

- Windows 10 или Windows 11, 64-разрядная версия;
- доступ в интернет для первоначальной настройки;
- действующая VPN-подписка или ссылка на поддерживаемую конфигурацию;
- права администратора для режима «Весь трафик» (TUN).

## Установка

1. Откройте страницу [последнего релиза](https://github.com/Apexmine22/kptVPN-release/releases/latest).
2. В разделе **Assets** скачайте файл `kptVPN_*_x64-setup.exe`.
3. Запустите установщик и дождитесь завершения установки.
4. Откройте kptVPN. При первом запуске приложение автоматически загрузит Xray и sing-box, проверит их контрольные суммы и установит доступное подписанное обновление.
5. Добавьте ссылку на подписку или конфигурацию, выберите сервер и подключитесь.

Установка выполняется для текущего пользователя. Ярлык kptVPN создаётся на рабочем столе.

## Режимы подключения

### Прокси

Запускает локальные SOCKS5- и HTTP-прокси. Права администратора не требуются. Программу, которая должна использовать VPN, необходимо настроить на соответствующий локальный прокси.

### Весь трафик

Создаёт системный TUN-туннель через sing-box и направляет через него приложения Windows. Для этого режима нужны права администратора — kptVPN предложит перезапустить приложение с необходимыми правами.

## Обновления и безопасность

- обновления kptVPN проверяются штатным механизмом Tauri и устанавливаются только после проверки цифровой подписи;
- Xray и sing-box загружаются из официальных выпусков, а архивы проверяются по SHA-256 перед установкой;
- новая версия ядра не прерывает активное подключение: она применяется после отключения VPN или следующего запуска;
- конфигурации, подписки и настройки приложения хранятся локально на компьютере.

Скачивайте установщик только из раздела [Releases](https://github.com/Apexmine22/kptVPN-release/releases) этого репозитория.

## Если что-то не работает

- **Первый запуск не завершается:** проверьте доступ в интернет и нажмите «Повторить».
- **Недоступен режим «Весь трафик»:** перезапустите kptVPN от имени администратора.
- **Сервер не подключается:** обновите подписку, выберите другой сервер и проверьте срок её действия.
- **Приложение закрылось, но VPN работает:** kptVPN мог свернуться в системный трей. Для полного выхода используйте меню значка в трее.

Диагностические сообщения доступны в разделе «Журнал». Если решить проблему не удалось, [создайте обращение](https://github.com/Apexmine22/kptVPN/issues) и приложите версию Windows, версию kptVPN и текст ошибки. Не публикуйте ссылки на подписки, UUID, пароли и другие секреты.
